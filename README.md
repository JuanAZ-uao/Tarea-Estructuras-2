# Challenge 05 - Task App con Firebase

Aplicacion de tareas con autenticacion Firebase, construida con React + TypeScript.

## Que incluye

- **Login / Registro / Logout** con Firebase Authentication
- **Rutas**: Login, Register y Home (protegida)
- **CRUD de Tareas**: crear, editar, eliminar y marcar como completada
- **Contexto de Auth**: maneja datos de login/registro en toda la app
- **Contexto de Tasks**: maneja las tareas a traves de las paginas
- **Custom Hooks**: useAuth y useTasks encapsulan la logica de Firebase
- **Bootstrap + SASS** para los estilos
